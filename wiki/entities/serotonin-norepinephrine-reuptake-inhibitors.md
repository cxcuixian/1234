# Serotonin-norepinephrine reuptake inhibitors

## Description

Serotonin-norepinephrine reuptake inhibitors are an antidepressant class associated with [[Extrapyramidal symptoms|extrapyramidal symptoms]], including possible [[Rigidity|rigidity]], [[Bradykinesia|bradykinesia]], and [[Tremor|tremor]]. The source states that both short-term and long-term antidepressant use can result in these symptoms. This class is discussed alongside [[Selective serotonin reuptake inhibitors|selective serotonin reuptake inhibitors]] and [[Norepinephrine-dopamine reuptake inhibitors|norepinephrine-dopamine reuptake inhibitors]], suggesting that multiple antidepressant mechanisms may be relevant to movement-related adverse effects. The available source does not provide a detailed mechanism or incidence estimate for this class. Examples include [[Duloxetine|duloxetine]].
