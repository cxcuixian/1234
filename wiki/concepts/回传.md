# 回传

## Definition

回传 is a learning procedure in which the discrepancy between a model’s output and its target is propagated backward through the model to guide parameter updates. It commonly forms a sequence with [[损失函数]], parameter adjustment, and reducing the distance between a model’s output and a desired value. In this way, it provides a concrete mechanism for [[反馈学习]] to improve a model.

## Key Characteristics

- Uses output error or loss information to guide changes to model parameters.
- Propagates information backward from the output toward earlier processing stages.
- Iteratively reduces the discrepancy between the model’s output and its target.
- Connects model optimization with feedback and error correction.
- Has an analogy with [[控制工程]], where error information is used to move a system toward a target state.
- Is closely associated with [[神经元]] and computational models in [[人工智能]].

## Applications

- Training neural-network models by calculating how parameter changes affect output error.
- Supporting iterative optimization through a combination of [[损失函数]] evaluation and parameter adjustment.
- Providing a mechanism for [[反馈学习]] in artificial-intelligence systems.
- Illustrating how error correction can move a system toward a desired state, alongside ideas from [[控制论]], [[负反馈]], and [[稳态]].
- Connecting learning procedures with broader discussions of [[科学研究]], [[数值分析]], and [[动物与机器中的控制与通信]].
