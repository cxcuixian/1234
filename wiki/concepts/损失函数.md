# 损失函数

## Definition

损失函数 is a mathematical function that measures the gap between a model’s output and a target or real value. In learning systems, this gap serves as an error signal: the system identifies the error, transmits it backward, and adjusts its parameters to reduce the loss. The concept therefore connects mathematical optimization with feedback learning and control engineering.

## Key Characteristics

- Quantifies the discrepancy between predicted outputs and target values.
- Converts model error into a mathematical value that can be optimized.
- Provides feedback for parameter adjustment and iterative learning.
- Usually aims to minimize error, often through gradient-based optimization.
- Represents error reduction as a formal mathematical process rather than merely an implementation detail.
- Its design influences what a model treats as important and how it balances competing errors.

## Applications

- Training neural networks and other machine-learning models.
- Implementing supervised learning through comparison with labeled targets.
- Supporting backpropagation and parameter optimization.
- Modeling feedback processes in control engineering and adaptive systems.
- Evaluating prediction, classification, regression, and decision-making performance.
- Formalizing objectives in artificial intelligence and numerical analysis.
