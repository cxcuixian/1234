# Oil-Based Lubrication

## Definition

Oil-based lubrication is a lubricant category that is incompatible with latex condoms. Using it with a latex condom can weaken the condom and undermine its protective function.

## Key Characteristics

- Refers to lubricants formulated with oil-based ingredients.
- Should not be used with latex condoms because oils can degrade latex.
- Connects lubricant-material compatibility with safer-sex practices.
- The warning concerns condom compatibility rather than a general recommendation for sexual activity.

## Applications

Oil-based lubrication may be considered only when it is compatible with the barrier material being used. When using latex condoms, a compatible alternative should be selected to help preserve contraceptive and infection-prevention protection.
